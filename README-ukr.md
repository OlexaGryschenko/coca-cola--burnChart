
## Особливості реалізації

* **HTML структура:** Використано базовий елемент `<input type="range">` для повзунків та тег `<canvas>`, який є контейнером для рендерингу графіка.
* **Підключення бібліотеки:** `Chart.js` підключається одним рядком через тег `<script src="...">`. Це демонструє підхід до використання зовнішніх скриптів через CDN.
* **Взаємодія з DOM:** За допомогою `getElementById` отримуються посилання на інпути, текстові вузли для виводу значень та контекст полотна (`canvas.getContext('2d')`).
* **Ініціалізація графіка:** Створюється екземпляр `new Chart()`, де вказується тип `line` (лінійний), масив міток для осі X (швидкості) та базові параметри візуалізації.
* **Обробка подій:** Метод `addEventListener('input', updateChart)` прив'язує функцію перерахунку до повзунків. Використання події `input` гарантує оновлення даних при кожному пікселі руху повзунка, на відміну від події `change`, яка спрацьовує лише після відпускання кнопки миші.
* **Динамічний перерахунок:** Функція `updateChart` зчитує поточні значення з інпутів, обчислює новий масив відстаней методом `map`, мутує масив `data` всередині об'єкта `burnChart` і викликає метод `burnChart.update()` для миттєвої перемальовки інтерфейсу.
